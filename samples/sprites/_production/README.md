# Animation production archive

The character-facing animation folders are intentionally minimal: one `README.md`, one authored timing-preview GIF, and one `frames/` directory containing the ordered transparent gameplay PNGs.

This archive preserves the supporting material removed from those folders without deleting it. Paths mirror the visible character and animation directory names. Depending on the age of the package, an archived animation may contain:

- generated and cleaned source atlases;
- aligned atlas exports;
- canonical endpoint copies;
- engine-neutral timing and event metadata;
- Godot `SpriteFrames` resources and controllers;
- generation prompts; and
- deterministic exporter and cleanup tools.

The visible animation README is the integration entry point and records the engine base speed, runtime speed scale, timing mode, total duration, uniform fallback, and exact per-frame delays.
