# Briar Knight rose vortex shield

A 16-frame, non-looping clockwise shield vortex of thorny vines, roses, and petals that builds around the planted Knight and unravels to idle.

## Playback timing

- Loop: No.
- Engine base playback speed: `18.0` FPS.
- Runtime `speed_scale`: `1.0`.
- Timing mode: variable per-frame durations.
- Total duration: `1.240` seconds.
- Uniform-timing fallback: approximately `12.9` FPS.
- Per-frame delays, in milliseconds: `80, 60, 60, 60, 60, 60, 70, 70, 80, 80, 80, 80, 80, 80, 100, 140`.

Frame 10 is the visual peak. The effect is presentation-only unless separately wired to gameplay.
