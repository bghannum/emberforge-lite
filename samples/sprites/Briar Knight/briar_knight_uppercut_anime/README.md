# Briar Knight anime uppercut

A 12-frame, non-looping two-handed sword uppercut with Japanese action-anime anticipation, cape motion, speed accents, and a red-white crescent.

## Playback timing

- Loop: No.
- Engine base playback speed: `20.0` FPS.
- Runtime `speed_scale`: `1.0`.
- Timing mode: variable per-frame durations.
- Total duration: `0.875` seconds.
- Uniform-timing fallback: approximately `13.7` FPS.
- Per-frame delays, in milliseconds: `100, 70, 70, 90, 55, 45, 40, 45, 70, 80, 90, 120`.

Frames 6–8 are active and frame 7 is the damage event. Frames 0 and 11 are exact canonical idle copies.

- `briar_knight_uppercut_anime_preview.gif`: authored timing preview.
