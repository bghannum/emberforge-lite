# Gravescribe fire-juggle idle

A 20-frame looping choice idle in which the Gravescribe tosses purple ghost-fire above the open book, catches it, and returns to the shared idle pose.

## Playback timing

- Loop: Yes.
- Engine base playback speed: `12.0` FPS.
- Runtime `speed_scale`: `1.0`.
- Timing mode: variable per-frame durations.
- Total duration: `1.600` seconds.
- Uniform-timing fallback: approximately `12.5` FPS.
- Per-frame delays, in milliseconds: `100, 80, 70, 70, 70, 70, 70, 80, 80, 80, 80, 80, 80, 80, 80, 80, 80, 70, 80, 120`.

Both loop endpoints are pixel-identical canonical idle frames. The flame is visual-only.
