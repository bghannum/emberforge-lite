# Demo actor assets

`ember-familiar/` is a synthetic, deterministic actor shipped so
`emberforge-lite demo` works offline with no credentials. Every file here is
generated by `emberforge_lite.demo.synthesize_demo_actor` from the same
deterministic byte generators the fake providers use — the sprite, animation,
and sound are procedural placeholders, not third-party art. They are covered by
this project's MIT license.
